Add a channel

Paste a YouTube channel link, or any video or playlist from it. Every upload joins your rotation and new ones are picked up automatically. Saved in this browser only.

How to get a key (free, about 5 minutes)
Open console.cloud.google.com, sign in and create a project (any name).
Search for YouTube Data API v3 at the top and click Enable.
Go to APIs & Services → Credentials → Create credentials → API key.
Optional but wise: restrict the key to YouTube Data API v3 and to the website .
Copy the key and paste it above. It stays in this browser.
